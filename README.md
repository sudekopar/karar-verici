# 🎯 İnteraktif Karar Verici (Decision Maker)

Kararsız kaldığınız anlarda sizin yerinize seçim yapan, modern ve eğlenceli bir web uygulaması. "Ne yesem?" veya "Hangi derse çalışsam?" gibi sorulara hızlı ve rastgele çözümler üretir.

## ✨ Özellikler
* **Dinamik Seçenek Listesi:** Kullanıcı istediği kadar seçenek ekleyebilir.
* **Rulet Efekti:** "Karar Ver" butonuna basıldığında seçenekler arasında hızlıca dönen bir animasyon çalışır.
* **Görsel Kutlama:** Seçim yapıldığında ekranda konfetiler patlar.
* **Modern Tasarım:** CSS ile güçlendirilmiş, kullanıcı dostu arayüz.

## 🛠️ Teknik Detaylar
* **HTML5:** Sayfa yapısı ve giriş alanları.
* **CSS3:** `@keyframes` kullanılarak oluşturulan özel animasyonlar ve şık tasarım.
* **JavaScript (ES6+):** * `Math.random()` algoritması ile rastgele seçim mantığı.
  * DOM manipülasyonu ile dinamik liste yönetimi.
  * `setInterval` ile görsel rulet döngüsü.
* **Kütüphane:** Görsel efektler için `canvas-confetti` kullanılmıştır.

## 🚀 Kurulum
Projeyi yerelinizde çalıştırmak için sadece `index.html` dosyasını tarayıcınızda açmanız yeterlidir.
